バドミントン向けアイソメトリックタイマー（ホーム画面追加版）

このフォルダーはPWA形式です。iPhoneのホーム画面からアプリのように起動できます。
ただし、ホーム画面に追加する前に、HTTPSで公開する必要があります。

【ファイル構成】
index.html                 タイマー本体
manifest.webmanifest       アプリ名・アイコン・起動方法の設定
sw.js                      オフライン用キャッシュ
icons/                     ホーム画面用アイコン

【GitHub Pagesで公開する手順】
1. GitHubにサインインし、新しいリポジトリを作成します。
   例：badminton-isometric-timer
   GitHub FreeでGitHub Pagesを使う場合は、リポジトリをPublic（公開）にします。
2. このZIPを解凍し、中にあるファイルとiconsフォルダーを、リポジトリの一番上の階層にアップロードします。
   ZIPファイル自体をアップロードするのではありません。
   index.html がリポジトリ直下にある状態にしてください。
3. リポジトリの Settings → Pages を開きます。
4. Build and deployment の Source を「Deploy from a branch」にします。
5. Branchを「main」、フォルダーを「/(root)」にして Save を押します。
6. 公開が完了すると、Settings → Pages にサイトURLが表示されます。
   URLは通常 https://GitHubのユーザー名.github.io/リポジトリ名/ の形式です。

【iPhoneでホーム画面に追加】
1. iPhoneのSafariで、公開されたサイトURLを開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. 「Webアプリとして開く」または「Open as Web App」をオンにします。
5. 「追加」を押します。

以後はホーム画面のアイコンから起動できます。初回にページを読み込んだ後は、必要なファイルが端末にキャッシュされ、オフラインでも基本機能を利用できます。

【注意】
・GitHub PagesのPublicリポジトリでは、アップロードしたファイルが公開されます。個人情報や秘密の情報は入れないでください。
・このタイマーは通知やサーバーへのデータ送信を行いません。
・iPhoneの省電力・画面ロック・OSの制御により、バックグラウンド中はカウント表示が止まったように見える場合があります。トレーニング中は画面を開いたまま使うのがおすすめです。
